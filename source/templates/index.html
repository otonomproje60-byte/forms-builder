Forms Builder

Lightweight Python form endpoint/builder — an OhMyForm alternative for self-hosted form submissions with email/webhook notifications.

🚀 Simple API

RESTful endpoints for creating forms and receiving submissions. No complex setup required.

📧 Email Notifications

Get notified via SMTP when a form is submitted. Customizable subject and recipient.

🔗 Webhook Support

Send submissions to any HTTP endpoint with HMAC signature verification.

🛡️ Spam Protection

Built-in honeypot field, pattern detection, and rate limiting.

📱 Embeddable Forms

Drop-in HTML/JS snippets to embed forms anywhere — static sites, SPAs, anywhere.

🐳 Docker Ready

Single container deployment with SQLite persistence. Zero external dependencies.

API Endpoints

POST /api/forms # Create a new form
GET /api/forms # List all forms
GET /api/forms/{id} # Get form details
POST /api/forms/{id}/submit # Submit form data (public)
GET /api/forms/{id}/submissions # List submissions (admin)
GET /embed/{id} # Embeddable HTML form
GET /embed/{id}.js # Embeddable JS snippet
GET /healthz # Health check
